
# Секущая плоскость и нарезка 3D-мешей

### 1. Как задается секущая плоскость в пространстве

Бесконечная плоскость однозначно описывается всего двумя параметрами:

* **Опорная точка `P0` (Point3D)** — любая точка в пространстве, через которую проходит плоскость (точка привязки).
* **Вектор нормали `N` (Vector3D)** — единичный вектор (длина равна 1), перпендикулярный плоскости. Он задает её ориентацию и указывает, где находится «лицевая» (положительная) сторона.

> **Важно:** нормаль — это **не** углы поворота (не градусы вроде `rotX, rotY, rotZ`). Нормаль — это направленный вектор смещения `(dX, dY, dZ)` с длиной ровно 1.

---

### 2. Определение положения точки относительно плоскости

Плоскость делит 3D-пространство на два полупространства. Чтобы узнать, с какой стороны находится любая вершина `V`, вычисляется **знаковое расстояние `d`** через скалярное произведение:

$$d = (V - P_0) \cdot N$$ *(в коде: `d = dot(V - P0, N)`)*

Результат `d` работает как простой детектор стороны:
* **`d > 0` (плюс)** — точка лежит **сверху / спереди** (по направлению нормали).
* **`d < 0` (минус)** — точка лежит **снизу / сзади** (с обратной стороны плоскости).
* **`d ≈ 0` (около нуля с учетом погрешности)** — точка лежит **строго на плоскости** (на «лезвии ножа»).

---

### 3. Логика распила треугольника

Чтобы понять, нужно ли резать треугольник с вершинами **A**, **B** и **C**, достаточно посчитать расстояние для каждой из них (`dA`, `dB`, `dC`):

* **Все знаки одинаковые** (все плюсы или все минусы) — треугольник целиком лежит по одну сторону, трогать его не нужно.
* **Знаки отличаются** (например, у `A` плюс, а у `B` и `C` минус) — ребра `AB` и `AC` пересекают плоскость, и треугольник нужно распиливать.

### 4. Реализация на C++

#### Определение расстояния от точки до плоскости

```cpp
struct Vector3 {
    float x, y, z;
};

// Вычисляет знаковое расстояние от плоскости до вершины
float GetDistanceToPlane(const Vector3& vertex, const Vector3& planeDot, const Vector3& planeNormal) {
    Vector3 diff = {
        vertex.x - planeDot.x,
        vertex.y - planeDot.y,
        vertex.z - planeDot.z
    };
    
    // Скалярное произведение (Dot Product)
    return (diff.x * planeNormal.x) + (diff.y * planeNormal.y) + (diff.z * planeNormal.z);
}
```

---

#### Поиск точной точки разреза на ребре

Допустим, ребро идет от вершины **A** к вершине **B**:
* У вершины **A** расстояние: `dA = +3.0` (сверху).
* У вершины **B** расстояние: `dB = -1.0` (снизу).

Знаки разные, значит ребро пересекает плоскость. Точка среза находится через простую пропорцию:

```cpp
float dA = GetDistanceToPlane(A, planeDot, planeNormal); // +3.0
float dB = GetDistanceToPlane(B, planeDot, planeNormal); // -1.0

// Процент пройденного пути от A к B до точки среза (значение от 0.0 до 1.0)
// t = 3.0 / (3.0 - (-1.0)) = 3.0 / 4.0 = 0.75 (75% пути)
float t = dA / (dA - dB);

// Координаты новой вершины на линии среза
Vector3 cutVertex = {
    A.x + (B.x - A.x) * t,
    A.y + (B.y - A.y) * t,
    A.z + (B.z - A.z) * t
};
```

### 5. Практическая реализация: структура `SPlane`

В реальном коде вся математика плоскости инкапсулируется в одну компактную и самодостаточную структуру:

```cpp
//-----------------------------------------------------------------------------
// SPlane: Математическое представление секущей плоскости (Точка + Нормаль)
//-----------------------------------------------------------------------------
struct SPlane
{
    Vector3 Point;  // Опорная точка плоскости (P0)
    Vector3 Normal; // Единичный вектор направления (N)

    // Конструктор по умолчанию: горизонтальная плоскость на высоте 0 с нормалью вверх
    SPlane()
        : Point(0.0f, 0.0f, 0.0f)
        , Normal(0.0f, 1.0f, 0.0f)
    {}

    // Конструктор с параметрами и автоматической нормализацией вектора
    SPlane(const Vector3& vPoint, const Vector3& vNormal)
        : Point(vPoint)
        , Normal(vNormal)
    {
        Normalize();
    }

    // Приведение нормали к единичной длине (с защитой от деления на 0)
    void Normalize()
    {
        const float fLenSq = Normal.x * Normal.x + Normal.y * Normal.y + Normal.z * Normal.z;
        if (fLenSq > 1e-8f)
        {
            const float fInvLen = 1.0f / sqrtf(fLenSq);
            Normal.x *= fInvLen;
            Normal.y *= fInvLen;
            Normal.z *= fInvLen;
        }
        else
        {
            // Если передан нулевой вектор — страхуемся дефолтной нормалью вверх
            Normal = Vector3(0.0f, 1.0f, 0.0f);
        }
    }

    // Знаковое расстояние от точки до плоскости: Dot(V - P0, N)
    float GetSignedDistance(const Vector3& vTestPoint) const
    {
        return (vTestPoint.x - Point.x) * Normal.x +
               (vTestPoint.y - Point.y) * Normal.y +
               (vTestPoint.z - Point.z) * Normal.z;
    }

    // Классификатор положения точки с учетом погрешности float (Epsilon)
    // Возвращает: +1 (сверху), -1 (снизу), 0 (строго на плоскости)
    int GetSide(const Vector3& vTestPoint, float fEpsilon = 1e-5f) const
    {
        const float fDist = GetSignedDistance(vTestPoint);
        if (fDist > fEpsilon)  return 1;
        if (fDist < -fEpsilon) return -1;
        return 0;
    }

    // Точная точка среза на отрезке [vA, vB]
    Vector3 GetIntersectionPoint(const Vector3& vA, const Vector3& vB, float fDistA, float fDistB) const
    {
        // Вычисляем фактор смещения от A к B: t = dA / (dA - dB)
        const float fT = fDistA / (fDistA - fDistB);

        return Vector3(
            vA.x + fT * (vB.x - vA.x),
            vA.y + fT * (vB.y - vA.y),
            vA.z + fT * (vB.z - vA.z)
        );
    }
};
```

---

### Разбор ключевых решений в коде

#### 1. Защита в методе `Normalize()`
Если в конструктор случайно передадут нулевой вектор `(0, 0, 0)`, обычное деление на длину приведет к `NaN` (делению на ноль). Проверка `fLenSq > 1e-8f` предотвращает сбой и безопасно сбрасывает нормаль в дефолтное состояние `(0, 1, 0)`.

#### 2. Зачем нужен `GetSide()` с параметром `fEpsilon`?
Числа с плавающей точкой (`float`) почти никогда не дают идеальный `0.0f` из-за погрешностей округления. 
* Вместо сравнения `d == 0` используется коридор погрешности `[-1e-5f, +1e-5f]`.
* Если расстояние попало в этот интервал, функция возвращает `0` — точка считается лежащей **строго на лезвии ножа**. Это критично, чтобы не плодить микроскопические треугольники-артефакты при нарезке.

#### 3. Оптимизация в `GetIntersectionPoint()`
Функция принимает уже заранее посчитанные `fDistA` и `fDistB`. Это избавляет от необходимости вычислять расстояние до плоскости повторно внутри каждого ребра — экономит процессорное время при обработке тысяч вершин.
