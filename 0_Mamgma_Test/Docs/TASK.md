# Реализовать программу для резки сетчатой поверхности плоскостью

### Исходные данные

**Поверхность**, состоящая из треугольников. Задана точками и индексами этих точек, использованных в треугольниках сетки поверхности. Индексы вершин треугольников определяют, из каких точек нужно строить треугольники поверхности. Индексы ориентированы так, что обход треугольника выполняется против часовой стрелки.

```
3 -------- 2
|        / |
|      /   |
|    /     |
|  /       |
0 -------- 1
```

> На рисунке показан пример простой поверхности, задающей квадрат в пространстве. Использовано 4 точки, определяющих два треугольника с помощью 6-ти индексов.  
> Для данного примера индексы точек будут такие: `0, 1, 2, 0, 2, 3`.

* Поверхность может состоять из произвольного количества треугольников.
* Поверхность на входе **НЕ** является выпуклой оболочкой.

**Плоскость.** Плоскость задается точкой и нормалью, может быть ориентирована в пространстве как угодно.

Данные для программы можно генерировать в файл формата XML и затем читать его оттуда. Как вариант, для начального теста можно формировать триангуляцию простой фигуры, вроде квадрата, потом поверхность параллелепипеда. Можно сгенерировать более сложные сетки: по сфере, цилиндру, с разбивкой по направлениям параметризации поверхностей.

---

### Цель задания

* Получить данные графических поверхностей (сеток) после разреза плоскостью исходной поверхности.
* Программа также должна содержать тестовый код для проверки корректности полученного результата разреза.
* Обратите внимание, что в результате резки входной сетки плоскостью может быть сколько угодно много новых сеток (например, если разрезать плоскостью входную сетку типа «волна синусоиды»).

---

### Пользовательский интерфейс

* Программа может быть реализована в консольном варианте. На вход даётся имя файла с данными поверхности-сетки и имя файла с данными плоскости, а на выходе файлы по одному для каждой полученной разрезанной несвязной сетки. В общем случае их может быть сколько угодно.
* Если в программе будет реализована визуализация исходной поверхности, плоскости резки и результатов резки, это будет засчитано как существенный бонус. В этом варианте для программы удобно будет взять за основу проект-пример формирования графики, скажем, на OpenGL. В интернете можно найти такие примеры. **(!)** Не надо подключать для работы с OpenGL никакие вспомогательные библиотеки с gitlab, они не нужны.
